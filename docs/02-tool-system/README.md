# 工具系统概述

工具系统是 OpenCode 的核心扩展机制，允许 AI 代理执行各种操作。

## 关键文件

| 文件 | 职责 |
|------|------|
| `tool/tool.ts` | 工具定义接口和辅助函数 |
| `tool/registry.ts` | 工具注册表，管理所有工具 |
| `tool/bash.ts` | Bash 命令执行工具 |
| `tool/read.ts` | 文件读取工具 |
| `tool/write.ts` | 文件写入工具 |
| `tool/edit.ts` | 文件编辑工具 |
| `tool/glob.ts` | 文件模式匹配工具 |
| `tool/grep.ts` | 内容搜索工具 |
| `tool/task.ts` | 子代理任务工具 |
| `tool/skill.ts` | 技能调用工具 |

## 内置工具列表

| 工具 | 用途 | 权限 |
|------|------|------|
| `bash` | 执行 shell 命令 | 需要用户确认 |
| `read` | 读取文件内容 | 自动允许 |
| `write` | 创建/覆盖文件 | 需要用户确认 |
| `edit` | 编辑文件内容 | 需要用户确认 |
| `glob` | 按模式搜索文件 | 自动允许 |
| `grep` | 搜索文件内容 | 自动允许 |
| `task` | 启动子代理任务 | 自动允许 |
| `skill` | 调用技能 | 自动允许 |
| `webfetch` | 获取网页内容 | 自动允许 |
| `websearch` | 搜索网页 | 自动允许 |
| `question` | 向用户提问 | 自动允许 |
| `todowrite` | 写入任务列表 | 自动允许 |
| `todoread` | 读取任务列表 | 自动允许 |
