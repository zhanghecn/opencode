# 多代理协作模式

## 概述

OpenCode 支持多代理协作，通过 Task 工具实现代理之间的任务分发和协作。

## Task 工具调用

### 基本用法

```typescript
// 主代理调用子代理
await Task({
  prompt: "Search for all API endpoint definitions",
  description: "Find API endpoints",
  subagent_type: "explore",
})
```

### 并行执行

```typescript
// 并行启动多个子代理
await Promise.all([
  Task({
    prompt: "Analyze frontend code structure",
    description: "Frontend analysis",
    subagent_type: "explore",
  }),
  Task({
    prompt: "Analyze backend code structure",
    description: "Backend analysis",
    subagent_type: "explore",
  }),
])
```

### 后台执行

```typescript
// 后台运行子代理
await Task({
  prompt: "Run comprehensive code analysis",
  description: "Code analysis",
  subagent_type: "general",
  run_in_background: true,
})
```

## 实现多代理系统

### 配置多个专业代理

```json
// opencode.json
{
  "agent": {
    "security-expert": {
      "name": "Security Expert",
      "description": "Analyzes code for security vulnerabilities",
      "mode": "subagent",
      "prompt": "You are a security expert...",
      "permission": {
        "*": "deny",
        "read": "allow",
        "grep": "allow"
      }
    },
    "performance-expert": {
      "name": "Performance Expert",
      "description": "Analyzes code for performance issues",
      "mode": "subagent",
      "prompt": "You are a performance expert...",
      "permission": {
        "*": "deny",
        "read": "allow",
        "grep": "allow",
        "bash": "allow"
      }
    },
    "doc-writer": {
      "name": "Documentation Writer",
      "description": "Generates documentation",
      "mode": "subagent",
      "prompt": "You are a documentation specialist...",
      "permission": {
        "*": "deny",
        "read": "allow",
        "write": {
          "docs/**": "allow"
        }
      }
    }
  }
}
```

### 使用技能协调代理

```markdown
<!-- .opencode/skill/code-quality.md -->
---
name: code-quality
description: Run comprehensive code quality analysis
---

# Code Quality Analysis

Execute the following analysis in parallel:

1. **Security Analysis**
   Use the security-expert agent to scan for vulnerabilities

2. **Performance Analysis**
   Use the performance-expert agent to identify bottlenecks

3. **Documentation Check**
   Use the doc-writer agent to verify documentation coverage

Compile results into a unified report.
```

## 通信机制

### 子代理结果返回

```typescript
// Task 工具返回子代理执行结果
const result = await Task({
  prompt: "Analyze the authentication module",
  subagent_type: "explore",
})

// result 包含子代理的完整输出
// 主代理可以基于此结果继续处理
```

### 上下文传递

```typescript
// 主代理可以在 prompt 中传递上下文
await Task({
  prompt: `Based on the following context:
${previousAnalysis}

Now analyze the related test files.`,
  subagent_type: "explore",
})
```

## 最佳实践

### 1. 合理划分职责

```
主代理: 协调、决策、用户交互
子代理: 专业任务、并行执行
```

### 2. 控制并行度

```typescript
// 避免同时启动过多子代理
const MAX_PARALLEL = 3
const batches = chunk(tasks, MAX_PARALLEL)
for (const batch of batches) {
  await Promise.all(batch.map(task => Task(task)))
}
```

### 3. 错误处理

```typescript
// 子代理失败时的处理
try {
  await Task({ ... })
} catch (error) {
  // 记录错误，尝试替代方案
}
```

### 4. 结果验证

```
主代理应验证子代理返回的结果:
- 检查结果完整性
- 验证格式正确性
- 确认任务完成度
```
